# Руководство по запуску экспертной системы

1. Откройте PowerShell в папке `solar_expert_system`.
2. Проверьте установку командой `swipl --version`.
3. Запустите программу командой:

   ```powershell
   swipl -q -s .\src\main.pl -g start -t halt
   ```

4. Последовательно отвечайте на вопросы. Для перечислимого признака вводите номер варианта. Для неизвестного числового значения вводите `?`.
5. После классификации изучите семейство, подтип, номера применённых правил, отсутствующие признаки и сообщения о противоречиях.
6. Выберите `1`, чтобы начать новый сеанс, или `0`, чтобы завершить программу.

Если `swipl` не находится, используйте полный путь:

```powershell
& 'C:\Program Files\swipl\bin\swipl.exe' -q -s .\src\main.pl -g start -t halt
```

Для запуска автоматических тестов:

```powershell
swipl -q -s .\tests\test_expert.pl
```
