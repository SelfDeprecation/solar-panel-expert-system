# Экспертная система классификации солнечных батарей

Локальная консольная экспертная система на SWI-Prolog. Программа принимает 22 признака фотоэлектрического модуля, классифицирует его по семейству технологии и подтипу, показывает применённые правила и сообщает о недостаточных или противоречивых данных.

## Требования

- SWI-Prolog 10.x;
- терминал с поддержкой UTF-8;
- подключение к интернету во время классификации не требуется.

Дополнительные библиотеки и пакеты SWI-Prolog не нужны.

## Запуск

Из корневой папки проекта:

```powershell
swipl -q -s .\src\main.pl -g start -t halt
```

Если команда `swipl` ещё не появилась в `PATH`:

```powershell
& 'C:\Program Files\swipl\bin\swipl.exe' -q -s .\src\main.pl -g start -t halt
```

Для каждого перечислимого признака вводится номер варианта. Для неизвестного числового значения следует ввести `?`.

## Тестирование

```powershell
swipl -q -s .\tests\test_expert.pl
```

Тестовый комплект проверяет:

- наличие ровно 60 пронумерованных продукционных правил;
- 25 эталонных карточек — по пять для каждого подтипа;
- отказ от подтипа при недостаточных данных;
- обнаружение противоречивых данных;
- проверку допустимости значений;
- независимость последовательных сеансов.

## Структура

```text
src/feature_schema.pl   — признаки, диапазоны и подписи
src/knowledge_base.pl   — пороги и 60 продукционных правил
src/engine.pl           — логический вывод и объяснение результата
src/dialog.pl           — консольный диалог
src/main.pl             — точка входа
tests/reference_cases.pl — 25 эталонных карточек
tests/test_expert.pl    — автоматические тесты plunit
```

## Категории классификации

Семейства:

- кристаллический кремний;
- тонкоплёночная технология.

Подтипы:

- монокристаллический кремний;
- поликристаллический кремний;
- аморфный кремний a-Si;
- теллурид кадмия CdTe;
- CIGS.

Результат программы носит справочный характер и не заменяет паспорт изделия, маркировку производителя, лабораторное исследование или заключение профильного специалиста.
